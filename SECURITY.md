# Security Policy

## Supported Versions

The following version(s) are supported:

| Version   | Supported          |
| -------   | ------------------ |
| >= 1.1.5  | :white_check_mark: |

## Reporting a Vulnerability

In order to report a vulnerability, feel free to email a well-formed vulnerability report to the repository maintainer at gh-maintainence AT xioup.com . Expect a response within one week.

Pull requests with fixes are also appreciated, although this package needs a good suite of regression tests before changes can be introduced, as its related npm package is downloaded several hundred thousand times per year. I'm currently working on a test suite (2026-10).
